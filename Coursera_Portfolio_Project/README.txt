COURSERA - PERSONAL PORTFOLIO CODED FROM SCRATCH
================================================

CONTENTS
- index.html: HTML5 page structure and portfolio content
- styles.css: all CSS including responsive breakpoints and dark theme
- script.js: mobile navigation, theme switcher, project filtering and current year

HOW TO OPEN
1. Unzip the folder.
2. Open index.html with Chrome, Edge, Firefox or Safari.
3. Scroll through the website and test the responsive layout using browser Developer Tools.

PERSONALIZE BEFORE PUBLISHING
- Search for "Your Name" in index.html and replace it with your real name.
- Change the email address "hello@example.com" to yours.
- Replace sample project concepts with projects you actually created.
- Change the About section and skills text to reflect your real experience.

GITHUB PAGES (URL FOR COURSERA)
1. Sign in to GitHub and create a public repository named "my-portfolio".
2. Upload index.html, styles.css and script.js to the repository root.
3. In the repository, open Settings > Pages.
4. In Build and deployment, select "Deploy from a branch".
5. Choose branch "main", folder "/ (root)", then Save.
6. Once Pages publishes, use the URL GitHub displays (usually
   https://YOUR-USERNAME.github.io/my-portfolio/).
7. Paste your *actual published URL* into Coursera's URL field.

W3C VALIDATION
- Go to https://validator.w3.org/nu/ and validate the published URL.
- Resolve any errors and save a screenshot showing the result.
- The project has been structurally checked locally; the official W3C validator
  result is NOT yet independently certified here.

WHAT TO DEMONSTRATE
- Responsive: Resize browser to desktop, tablet and mobile widths.
- Visual style: Show typography, layout, cards, spacing, colors and custom CSS.
- Extras: Try the dark-mode button, category filter and mobile navigation.
- Accessibility: Use Tab to navigate, activate controls by keyboard,
  and use the Skip to main content link.
